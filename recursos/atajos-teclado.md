# Atajos de teclado

En Mac, `Cmd` sustituye a `Ctrl` salvo que se indique otra cosa. Lista completa: [Microsoft Support (Windows)](https://support.office.com/en-us/article/Excel-keyboard-shortcuts-and-function-keys-for-Windows-1798d9d5-842a-42b8-9c99-9b7213f0040f) · [Microsoft Support (Mac)](https://support.office.com/en-us/article/Keyboard-shortcuts-in-Excel-2016-for-Mac-acf5419e-1f87-444d-962f-4e951a658ccd).

> Cobertura: Essentials (módulos 1-6), Intermediate I (módulos 1-6) e Intermediate II (módulos 1-5; el módulo 5 no trajo atajos nuevos en su Toolbox). Se amplía al cerrar cada módulo de los cursos siguientes.

## Archivo e impresión
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Ctrl + N` | Nuevo libro | Essentials M1 |
| `Ctrl + O` | Abrir libro | Essentials M1 |
| `Ctrl + S` | Guardar | Essentials M1 |
| `Ctrl + W` | Cerrar libro | Essentials M1 |
| `Ctrl + P` | Abrir el diálogo de impresión | Essentials M5 |
| `Ctrl + F2` | Abrir la vista previa de impresión | Essentials M5 |

## Edición
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Ctrl + Z` | Deshacer (no sirve para *Mover gráfico* ni para eliminar una hoja con contenido) | Essentials M1 |
| `Ctrl + Y` | Rehacer / repetir un paso varias veces | Essentials M1 |
| `Ctrl + X` / `Ctrl + C` / `Ctrl + V` | Cortar / copiar / pegar | Essentials M5 |
| `Ctrl + Alt + V` | Pegado especial (valores, formato, transponer...) | Essentials M1 |
| `Alt + Enter` | Salto de línea dentro de la celda | Essentials M1 |
| `Ctrl + Enter` | Terminar de editar **y quedarse en la misma celda** | Intermediate I M3 |
| `Ctrl + ;` | Insertar la fecha de hoy como valor **fijo** | Intermediate I M2 |
| `Ctrl + Shift + ;` (Mac: `Cmd + ;`) | Insertar la hora actual como valor **fijo** | Intermediate I M2 |
| `Ctrl + Shift + +` (Mac: `Control + I`) | Con una fila o columna **entera seleccionada**, insertar una fila o columna nueva (antes se vio como `Ctrl + Signo más`) | Essentials M4, Intermediate II M2 |
| `Ctrl + -` (Windows y Mac) | Con una fila o columna seleccionada, eliminarla | Essentials M4, Intermediate II M2 |
| `Ctrl + F` / `Ctrl + H` | Buscar / Reemplazar | Essentials M4 |

## Fórmulas y nombres
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `F4` (Mac: `Fn + F4` o `Cmd + T`) | Justo después de escribir una referencia en la fórmula: una pulsación la hace absoluta; si se sigue pulsando, cicla `$D$4` → `D$4` → `$D4` → relativa `D4` | Essentials M2, Intermediate I M4, Intermediate II M3 |
| `Tab` | Aceptar la función que Excel sugiere en el autocompletado mientras se escribe | Intermediate II M3 |
| `` Ctrl + ` `` | Mostrar las fórmulas en vez de sus resultados | Essentials M2 |
| `Shift + F3` (Mac: `Ctrl + A`) | Asistente de funciones (Formula Builder) | Essentials M2 |
| `Alt + =` | Autosuma | Essentials M2 |
| `F2` | Editar la fórmula mostrando los **precedentes de cada argumento codificados por colores** | Intermediate II M4 |
| `F9` | Recalcular las fórmulas de **todos los libros abiertos** | Intermediate II M4 |
| `Shift + F9` | Recalcular las fórmulas solo de la **hoja activa** | Intermediate II M4 |
| `Ctrl + [` | Ir a las celdas **precedentes** de la celda activa | Intermediate II M4 |
| `Ctrl + ]` | Ir a las celdas **dependientes** de la celda activa | Intermediate II M4 |
| `Ctrl` + clic (dentro de una función) | Inserta la coma entre referencias, ej. `CONCAT(A2,D2,G2)` | Intermediate I M2 |
| `F3` | Pegar nombre (lista de rangos con nombre) | Intermediate I M3 |
| `Ctrl + F3` | Administrador de nombres (solo Windows) | Intermediate I M3 |
| `Cmd + fn + F3` · `Cmd + F3` · `Ctrl + L` | Definir nombre (solo Mac; el Intermediate I indica la primera forma, el Intermediate II las otras dos, según cómo use las teclas F el teclado) | Intermediate I M3, Intermediate II M1 |
| `Ctrl + Shift + F3` (Mac: `Cmd + Shift + fn + F3` o `Cmd + Shift + F3`) | Crear nombres desde la selección | Intermediate I M3, Intermediate II M1 |

## Formato
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` | Negrita / cursiva / subrayado | Essentials M3 |
| `Ctrl + 1` | Diálogo "Formato de celdas" | Essentials M3 |
| `Ctrl + 5` | Tachado | Essentials M3 |
| `Ctrl + Shift + &` | Borde de contorno a la selección | Essentials M3 |
| `Ctrl + Shift + ~` | Formato General (quita el formato de número) | Essentials M3 |

## Navegación
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Re Pág` / `Av Pág` | Subir / bajar una página | Essentials M1 |
| `Ctrl + Flecha` | Saltar al borde del bloque de datos | Essentials M1 |
| `Ctrl + Inicio` / `Ctrl + Fin` | Ir a `A1` / a la última celda usada (sin tecla Inicio: `Ctrl + Fn + Inicio`) | Essentials M1 |
| `F5` o `Ctrl + G` | Ir a... (celda, rango o rango con nombre) | Essentials M1 |
| `Ctrl + Rueda del mouse` | Zoom | Essentials M1 |
| `Ctrl + Av Pág` / `Ctrl + Re Pág` (Mac: `Option + →` / `Option + ←`) | Hoja siguiente / hoja anterior | Essentials M2, Intermediate I M1 |
| `Ctrl + .` | Moverse entre las esquinas de una tabla | Intermediate I M5 |

> Tip de navegación: clic derecho sobre las flechas junto a las pestañas de hoja abre el diálogo **Activar** con la lista de hojas del libro.

## Selección
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Ctrl + A` | Seleccionar todo (primero el bloque de datos, luego la hoja; en una tabla, selecciona la tabla) | Essentials M1, Intermediate I M5 |
| `Ctrl + Shift + Flecha` | Seleccionar hasta el borde de los datos; con otra flecha se extiende en otra dirección | Essentials M1, Intermediate I M3 |
| `Shift` + clic | Seleccionar un rango entre la primera y la última celda | Essentials M5 |
| `Ctrl` + clic | Seleccionar celdas, filas o columnas **no contiguas** | Essentials M5 |
| `Shift + Espacio` | Seleccionar la fila (en una tabla, la fila de la tabla) | Intermediate I M5 |
| `Ctrl + Espacio` | Seleccionar la columna (en una tabla, la columna de la tabla) | Intermediate I M5 |

## Filas y columnas
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Ctrl + 0` / `Ctrl + 9` | Ocultar la columna / la fila de la celda seleccionada | Essentials M4 |
| `Ctrl + Shift + 0` / `Ctrl + Shift + 9` | Mostrar la columna / la fila oculta (seleccionando las celdas que la rodean) | Essentials M4 |

> En algunas versiones de Windows, `Ctrl + Shift + 0` está asignado a una función del sistema; si no responde, hay que desactivar esa asignación en Windows.

## Datos, tablas y tablas dinámicas
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `Ctrl + Shift + L` (Mac: `Cmd + Shift + F`) | Activar/desactivar el filtro | Essentials M4 |
| `Ctrl + T` (Mac: `Cmd + T` o `Ctrl + T`) | Insertar tabla | Intermediate I M5 |
| `Alt + F5` | Actualizar la tabla dinámica seleccionada | Intermediate I M6 |
| `Ctrl + Alt + F5` | Actualizar todas las tablas dinámicas y conexiones | Intermediate I M6 |

## Gráficos
| Atajo | Acción | Dónde se vio |
|---|---|---|
| `F11` | Insertar un gráfico en una hoja de gráfico nueva (en Mac, con `fn`) | Essentials M6 |
| `Alt + F1` | Insertar un gráfico incrustado en la hoja actual | Essentials M6 |
| `Ctrl + D` | Duplicar un gráfico | Intermediate I M4 |
| `Ctrl + Shift + >` | Aumentar el tamaño de fuente de un elemento del gráfico (solo Windows) | Intermediate I M4 |

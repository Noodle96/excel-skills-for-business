# 01 · Excel Skills for Business: Essentials

Cada módulo (semana) tiene su carpeta `modulo-NN` dentro de `notas/` y `material_curso/`. Los `.xlsx` que trae el curso (en `material_curso/modulo-NN/`) son el ejercicio: el que termina en `Soln` es la solución, el otro (mismo nombre sin `Soln`) es el que se resuelve directamente.

## Objetivos por semana

| Semana | Tema | Vas a poder... |
|---|---|---|
| 1 | Critical Core of Excel | - Describir los componentes clave de la interfaz de usuario de Excel<br>- Operar los controles de navegación esenciales<br>- Realizar entrada de datos básica en Excel<br>- Explicar la terminología básica de Excel |
| 2 | Excel Calculations | - Explicar la sintaxis de fórmulas y funciones básicas<br>- Usar fórmulas y funciones para hacer cálculos simples<br>- Describir la diferencia entre referencias de celda relativas y absolutas |
| 3 | Excel Formatting Essentials | - Dar ejemplos de las herramientas de formato clave y sus usos en Excel<br>- Modificar hojas de cálculo con estilos y temas de Excel<br>- Explicar el uso del formato de número en Excel<br>- Dar formato a un conjunto de datos en bruto usando las herramientas de Excel |
| 4 | Excel Data Management | - Gestionar filas, columnas y hojas<br>- Identificar, recuperar y cambiar datos en las hojas de cálculo<br>- Explicar cómo operar el Formato Condicional en Excel<br>- Usar la herramienta de formato condicional para resaltar datos específicos |
| 5 | Printing Excel Spreadsheets | - Identificar las herramientas y opciones clave de impresión en Excel<br>- Optimizar una hoja de cálculo para impresión<br>- Crear una hoja de cálculo para impresión con elementos repetidos |
| 6 | Excel Data Charts | - Describir los tipos básicos de gráficos en Excel<br>- Producir gráficos básicos en Excel<br>- Modificar gráficos en Excel |

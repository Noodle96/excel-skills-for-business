# 03 · Excel Skills for Business: Intermediate II

Cada módulo (semana) tiene su carpeta `modulo-NN` dentro de `notas/` y `material_curso/`. Los `.xlsx` que trae el curso (en `material_curso/modulo-NN/`) son el ejercicio: el que termina en `Soln` es la solución, el otro (mismo nombre sin `Soln`) es el que se resuelve directamente.

## Sobre el curso

Tercer curso de la especialización: amplía lo visto en Essentials e Intermediate I para manejar conjuntos de datos más grandes, crear hojas más sofisticadas, automatizar tareas y prevenir/revisar errores. Se sigue el caso de Alex Fernando, un consultor de Excel al que llaman cuando las hojas fallan o necesitan mejorar.

- **Requisitos previos**: manejo sólido de tablas, rangos con nombre y funciones más complejas (lo cubierto en los dos primeros cursos). Se usa Excel 2016 (Office 365).
- **Estructura de cada semana**: Escenario (introducción y discusión), videos de práctica con su libro de Excel, un quiz práctico tras cada video, reto de práctica semanal y Toolbox (atajos, terminología y ninja tips).
- **Evaluación**: 6 tareas semanales de 10% cada una, más una tarea final de 40%.

## Objetivos del curso

Al terminar el curso podrás:

1. Revisar y prevenir errores en hojas de cálculo (Semanas 1, 4)
2. Crear automatización en hojas de cálculo (Semanas 1, 3, 6)
3. Aplicar fórmulas avanzadas y lógica condicional para ayudar a tomar decisiones (Semanas 2, 3, 5)
4. Crear hojas de cálculo que ayuden a pronosticar y modelar datos (Semana 5)

### Objetivos por semana

| Semana | Tema | Vas a poder... |
|---|---|---|
| 1 | Data Validation | - Configurar la validación de datos<br>- Trabajar con fórmulas en la validación de datos<br>- Crear y usar listas desplegables<br>- Crear y aplicar formatos condicionales personalizados |
| 2 | Conditional Logic | - Explicar el concepto de lógica condicional en fórmulas<br>- Evaluar datos de una celda con pruebas lógicas<br>- Usar operaciones condicionales en funciones (IF, AND, OR)<br>- Evaluar datos con funciones IF anidadas |
| 3 | Automating Lookups | - Usar VLOOKUP para encontrar y mostrar el contenido de una celda<br>- Identificar el uso y los requisitos de la búsqueda por rango<br>- Buscar datos con las funciones INDEX y MATCH |
| 4 | Formula Auditing and Protection | - Configurar las opciones de cálculo de fórmulas<br>- Rastrear precedentes y dependientes<br>- Explicar cómo revisar errores en una hoja de cálculo<br>- Proteger libros y hojas de cálculo |
| 5 | Data Modelling | - Modelar distintos escenarios según entradas, supuestos y/o resultados<br>- Usar Buscar objetivo (Goal Seek) y Solver para investigar qué parámetros de entrada producen un resultado deseado<br>- Usar Tablas de datos y el Administrador de escenarios |
| 6 | Recording Macros | - Identificar los usos de las macros en Excel<br>- Crear macros para automatizar tareas repetitivas<br>- Editar macros para ampliar su funcionalidad<br>- Administrar macros de forma eficiente |

# 02 · Excel Skills for Business: Intermediate I

Cada módulo (semana) tiene su carpeta `modulo-NN` dentro de `notas/` y `material_curso/`. Los `.xlsx` que trae el curso (en `material_curso/modulo-NN/`) son el ejercicio: el que termina en `Soln` es la solución, el otro (mismo nombre sin `Soln`) es el que se resuelve directamente.

## Objetivos del curso

Al terminar el curso podrás:

1. Gestionar grandes conjuntos de datos de forma eficiente (Semanas 1, 2, 3, 4, 5)
2. Extraer información relevante de grandes conjuntos de datos (Semanas 4, 5, 6)
3. Presentar datos y comunicar información de forma efectiva (Semanas 2, 4, 5, 6)
4. Trabajar con datos provenientes de varias fuentes (Semanas 1, 3)

### Objetivos por semana

| Semana | Tema | Vas a poder... |
|---|---|---|
| 1 | Multiple Worksheets & Workbooks | - Comparar métodos para combinar datos de varias fuentes<br>- Hacer cálculos entre libros/hojas<br>- Gestionar datos repartidos en varios libros/hojas |
| 2 | Text & Date Functions | - Explicar el uso de funciones de texto y fecha<br>- Trabajar con funciones anidadas<br>- Extraer inteligencia de negocio con funciones de fecha<br>- Combinar o dividir cadenas de texto |
| 3 | Named Ranges | - Describir el uso de rangos con nombre<br>- Crearlos con distintos métodos<br>- Mejorar cálculos apoyándote en ellos |
| 4 | Summarising Data | - Explicar la sintaxis de fórmulas más avanzadas<br>- Usar funciones para extraer información resumida<br>- Generar representaciones gráficas de los datos |
| 5 | Tables | - Crear y modificar tablas<br>- Aplicarles formato, orden y filtros<br>- Agregarles datos<br>- Explicar la terminología propia de las tablas en Excel |
| 6 | Pivot Tables, Charts and Slicers | - Crear tablas dinámicas, gráficos dinámicos y slicers<br>- Usar tablas dinámicas para extraer significado de los datos<br>- Crear dashboards visuales con slicers y gráficos dinámicos<br>- Filtrar información de varias fuentes con slicers |
